# Tailoring Management & Marketplace SaaS

A production-ready, multi-tenant tailoring management platform built with Next.js, React 19, Convex, and TypeScript.

## 🚀 Features

### Multi-Tenant Architecture
- Complete organization isolation
- Role-based access control (Admin, Manager, Worker, Customer)
- Customizable branding per organization
- Subscription-based feature gating

### Order Management
- Track orders through production stages (Cutting → Sewing → Finishing → Delivery)
- Customer and dependant management
- Measurement tracking and history
- Order status and deadline alerts

### Task Management
- Assign tasks to workers with material allocations
- Track material consumption
- Worker performance ratings
- Deadline monitoring with overdue alerts

### Inventory & Materials
- Material inventory tracking with ledger system
- Fabric catalog for customer browsing
- Low stock alerts
- Purchase and consumption tracking

### Communication
- In-app chat between roles
- Role-restricted conversations
- Real-time messaging

### Trust & Verification
- Organization verification system
- Document upload (CAC, BVN, Bank)
- Verification badges

### Analytics (Pro+)
- Business performance metrics
- Order trends
- Worker productivity
- Material consumption analysis

## 🛠️ Tech Stack

- **Frontend**: Next.js 15, React 19, TypeScript
- **Styling**: Tailwind CSS v4
- **Backend**: Convex
- **Auth**: Convex Auth
- **State Management**: Server-driven with Convex real-time queries
- **Charts**: Recharts
- **Icons**: Lucide React

## 📦 Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd tailoring-saas
```

2. Install dependencies:
```bash
npm install
```

3. Set up Convex:
```bash
npx convex dev
```

4. Set up environment variables:
```bash
cp .env.example .env.local
```

Add your Convex deployment URL to `.env.local`:
```
NEXT_PUBLIC_CONVEX_URL=your_convex_url
```

5. Run the development server:
```bash
npm run dev
```

6. Open [http://localhost:3000](http://localhost:3000)
